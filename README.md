# 🏫 Campus Chatbot

AI assistant that answers questions about campus resources, events, and policies.

**Author:** Pranay M

## Features
| Module | Description |
|--------|-------------|
| Resource Finder | Find campus resources |
| Event Informer | Get event information |
| Policy Explainer | Explain campus policies |
| Direction Provider | Get campus directions |
| Hours Checker | Check operating hours |
| Contact Finder | Find department contacts |
| FAQ Handler | Answer common questions |
| Emergency Info | Emergency information |
| Service Recommender | Recommend services |
| Conversation Manager | Maintain chat context |

## Usage
```bash
pip install -r requirements.txt && python main.py
```
